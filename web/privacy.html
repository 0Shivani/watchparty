Privacy Policy

Last updated: July 26, 2026

Picnic is a Chrome extension that synchronizes video playback and chat between friends. This policy describes what data the extension handles and how it is used.

Data the extension transmits

To make watch parties work, the extension sends the following to the party server (operated by us or self-hosted by the room's host):

  • Display name - a nickname you choose when joining a room. It does not need to be your real name.
  • Chat messages - messages you type in the chat overlay are relayed in real time to the other members of your room.
  • Playback events - play, pause, and seek actions with their video timestamps, so everyone's playback stays in sync.
  • Watch page URL - when you create an invite link, the URL of the video you are watching is sent to the server so invited friends can be redirected to the same video.

How data is stored

  • Rooms exist in memory only on the server. Chat messages are relayed and never written to a database. When a room empties, all of its data (including the watch URL) is deleted within about 45 seconds.
  • Invite links expire automatically after 15 minutes.
  • Your display name, server URL, and room code are stored locally in your browser (chrome.storage.local) so your session survives closing the popup. They never leave your device except as described above.

What we do not do

  • No analytics, tracking, or telemetry of any kind.
  • No collection of browsing history, page content, or account data.
  • No selling or sharing of any data with third parties.
  • No use of data for advertising, profiling, or creditworthiness.

Permissions

The extension only runs on YouTube, Netflix, Prime Video, and JioHotstar. Access to any other website is granted only if you explicitly approve it through a browser permission prompt, and can be revoked at any time from the extension settings.

Contact

Questions about this policy can be raised on the project's GitHub repository: github.com/0Shivani/watchparty.
