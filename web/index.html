How it works

  1. 1

    Install the extension

    Add WatchParty to Chrome from the Web Store.

  2. 2

    Connect to a server

    Open the popup and paste your WatchParty server URL (for example https://your-server.onrender.com).

  3. 3

    Create or join a room

    Start a room on any supported site, then share the invite link.

  4. 4

    Press play together

    Everyone's playback and chat stay in sync automatically.
